# Assembly help — Mock prototype

Static Mock UI for an in-app assembly help flow (chat + 3D).

**Clone:** https://github.com/tracyqjx/ikea-assembly-help-prototype

```bash
git clone https://github.com/tracyqjx/ikea-assembly-help-prototype.git
cd ikea-assembly-help-prototype
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173 (or point any static server at this folder).
